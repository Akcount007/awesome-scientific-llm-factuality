# Verified Datasets
- **SciFact**: Contains expert-written scientific claims paired with evidence-containing abstracts, allowing researchers to evaluate whether an AI system can correctly identify if an abstract supports or refutes a claim[cite: 2].
- **PubMedQA**: A novel question-answering dataset collected directly from PubMed abstracts that requires models to answer research questions with yes, no, or maybe[cite: 2].
- **TruthfulQA**: A benchmark comprising adversarial questions designed to trigger false beliefs and measure how models adopt human misconceptions[cite: 2].
- **GPQA**: A graduate-level, Google-proof dataset for testing expert-level domain reasoning in biology, chemistry, and physics.
